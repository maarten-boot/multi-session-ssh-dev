Sessions

Commands (this session's, before the ones in Settings)

Path mapping: where the agent host sees your local directories. Leave both empty if paths are the same on both machines.

Each session gets <folder>/<directory>-<id> there. See docs/CONNECTIVITY.md for the trade-offs of each mode.

Settings

Tabs (order and which are shown)
Command menu (Local and Remote tabs: right-click, or Commands ▾ in the bar)

For every session, after its own (Edit… → Commands). With “run” ticked the command is typed and Enter pressed; without, it is only typed.

Start commands (what a session's Remote tab starts in a new tmux session)

Each session picks one in Edit… (Start in new remote session). The command runs in the agent host's interactive login shell; an empty command is just that shell. When it ends, a shell takes over.

Background and what else to check: docs/CONNECTIVITY.md in the project.

Saving agent copies before quitting…


        
Everything in each working copy on its agent host is copied here (Full ▾ → Save agent copy); the app quits when that is done. Settings → Backups and recordings turns it off.
