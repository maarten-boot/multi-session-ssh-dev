Sessions

Commands (this session's, before the ones in Settings)

Each session under this host runs in its own container, built from its Dockerfile (session menu → Dockerfile…), with the session directory mounted at the same path and ssh reachable only from this computer. Settings → Containers chooses Podman or Docker.

A plain login only has the Remote, Notes, Web and Q&A tabs; its shell starts in the login's home or a folder you give. Each session can still choose otherwise; the file access and path fields below then only apply to sessions that do.

Path mapping: where the agent host sees your local directories. Leave both empty if paths are the same on both machines.

Each session gets <folder>/<directory>-<id> there. See docs/CONNECTIVITY.md for the trade-offs of each mode.

Tabs (order and which are shown)

                

            

        

        

            

                
                
                
                
Frees its memory on the agent host; it resumes (claude --resume) when you open the session. Not the session on screen, not while it asks a question or runs a command. For claude started after this is set (Edit… sets a session's own).

                

                    
                    
                    
                    
                    
                    
                

            

        

        

            
Command menu (Local and Remote tabs: right-click, or Commands ▾ in the bar)

            
For every session, after its own (Edit… → Commands). With “run” ticked the command is typed and Enter pressed; without, it is only typed. “Local” or “Remote” always types it into that tab, also when chosen in the other one, which stays on screen (e.g. git push from this computer while you watch the Remote tab).

            

            
Start commands (what a session's Remote tab starts in a new tmux session)

            
Each session picks one in Edit… (Start in new remote session). The command runs in the agent host's interactive login shell; an empty command is just that shell. When it ends, a shell takes over.
